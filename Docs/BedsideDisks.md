# Тумбочка, осмотр комнаты и диски

На карту ставится **BP_BedsideCabinet** из `/Game/NENS/Environment/Interior/Blueprints`. Он также добавлен в коллекцию **NENS_Demo_Props_Ready**. Временный внешний вид — уменьшенный `SPR_Props_MetalCabinet`; остальная логика использует существующий `BP_InteractableBase`, белое кольцо и E.

Путь игрока: **E → сцена с кроватью → клик по тумбочке справа → диски**. Смена сцены проходит внутри одного окна и одного сеанса; карта и персонаж не пересоздаются. Esc и Exit плавно закрывают окно на любом этапе. Выход до победы начинает новую попытку при следующем входе. После победы у конкретного экземпляра тумбочки отключаются E и кольцо; сама мебель остаётся видимой. Результат живёт до конца текущего Play.

Когда художники подготовят мебель, открой `BP_BedsideCabinet → Viewport → Sprite_Visual` и замени **Source Sprite**. Сейчас Relative Scale равен 0.45 из-за размеров временного металлического шкафа; под новый спрайт подстрой масштаб. Sphere_Awareness, Sphere_Interaction и Minigame оставь на месте. При необходимости меняй размеры сфер и положение подсказки, как у других интерактивных предметов.

## Оформление и область клика

Существующий `/Game/Minigames/Disks/WBP_DiskBoard` теперь использует родителя `DisksMinigameWidget`. В его Designer:

- `Canvas_Minigame` — общий макет, заголовок, статус и короткое управление.
- `ScenePages` — две страницы. Индекс **0** показывает комнату, индекс **1** — диски. В сохранённом Designer выбран индекс 1; при взаимодействии в игре автоматически открывается индекс 0.
- `Canvas_Container → Image_Container` — новая `T_Inspection_Container` с сохранёнными пропорциями.
- `Canvas_Container → Btn_Cabinet` — прозрачная область клика по тумбочке справа, с мягкой подсветкой при наведении. Положение/размер меняются здесь, если художник изменит композицию.
- `Canvas_Disks → Board` — исходное поле 1000 × 1000 с прежними текстурами, начальными углами и правилами трёх колец.

В **Graph → Class Defaults → Minigame** доступны:

| Раздел / поле | По умолчанию | Назначение |
|---|---:|---|
| Transition / Scene Fade In Seconds | 0.30 | Появление окна |
| Transition / Scene Fade Out Seconds | 0.24 | Закрытие окна |
| Transition / Stage Fade Seconds | 0.20 | Каждый этап перехода от комнаты к дискам |
| Mist / Mist Opacity | 0.42 | Плотность верхней дымки, 0 отключает |
| Mist / Mist Speed | 0.35 | Скорость движения дымки |
| Mist / Mist Height | 0.28 | Доля высоты окна для дымки |
| Appearance / Screen Padding | 32 | Отступ композиции от краёв |
| Appearance / Interface Font | IM Fell English | Общий шрифт, размеры задаются в Designer |

Дымка и боковой градиент рисуются процедурно без дополнительных текстур. Кнопки и подсказки масштабируются вместе с полем. Управление в головоломке короткое: **Hold left click — Turn**, **Esc — Exit**.

## Сохранённая механика

Удержание ЛКМ вращает выбранное кольцо по часовой стрелке со скоростью 60°/с. Пороговые радиусы выбора: 166, 359 и 500 единиц исходного поля. Начальные углы: внутреннее 120°, среднее 230°, внешнее 300°. Для победы нужно отпустить ЛКМ, когда все три кольца стоят в пределах 10° от исходной картинки.

Координаты нажатия теперь берутся из самого события мыши и переводятся в координаты поля: масштабирование и перемещение окна не сбивают выбор кольца. После победы рисунок мягко доворачивается на последние несколько градусов, появляется `Image restored`, затем окно закрывается. Прежний `OnDisksSolved` с задержкой 1.5 секунды сохранён; `Minigame.OnSucceeded` фиксирует результат сразу при победе.

`L_Test_Disks` остаётся самостоятельной проверочной картой и открывает сразу диски. Основные карты не изменялись. `Tools/configure_disks_minigame.py` — первоначальная настройка через Unreal API; перед обычным Play его запускать не нужно. Исходная новая картинка сохранена в `SourceArt/Inspection/T_Inspection_Container.png` без изменения пикселей.
