# Головоломка напольных часов

`BP_FloorClock` использует один сеанс осмотра для двух этапов. При первом входе E показывает закрытые часы и две стрелки. Правильная установка запускает секундный плавный переход к открытому отделению с перфокартой. Escape работает на любом этапе, в том числе при перетаскивании и во время перехода.

## Управление

1. Зажать ЛКМ на стрелке сбоку и отпустить на циферблате. Она закрепляется в центре. Бросок мимо возвращает стрелку на плашку.
2. Зажать конец установленной стрелки и двигать мышь вокруг центра. Угол фиксируется при отпускании, с небольшим шагом привязки.
3. Колесо мыши или клавиши ←/→ точно поворачивают выбранную установленную стрелку. Tab и кнопки «Hour hand»/«Minute hand» меняют выбор, в том числе при наложении стрелок.
4. Сверить положение с картиной Гослинга. После совпадения обе стрелки фиксируются, открывается отделение.
5. Нажать на перфокарту, затем выйти по Escape.

У незавершённых часов сохраняются уже установленные стрелки и их углы. Escape отменяет только ещё не отпущенное перетаскивание/вращение. После решения повторный вход сразу открывает отделение, даже если игрок вышел во время перехода. Если карту не взять, часы остаются доступны. После сбора и выхода скрываются E и кольцо, сам объект остаётся видимым. Прогресс независим у разных экземпляров и действует до конца текущего Play; SaveGame пока нет.

## Редактирование без изменения C++

Все новые ресурсы находятся в `/Game/NENS/UI/Inspection`:

| Ресурс | Что менять |
| --- | --- |
| `DA_ClockPuzzle_FloorClock` | Закрытый фон, геометрию циферблата, изображения/крепления стрелок, начальные и правильные углы, допуск, шаг вращения, длительность перехода, Interface Font и Tray Scale |
| `DA_Inspection_FloorClock` | Открытый фон, размер макета и перфокарту в Pickups |
| `WBP_ClockInspection` | Общую компоновку экрана; родитель — `ClockInspectionWidget` |

Углы задаются по часовой стрелке: 0° = XII, 90° = III, 180° = VI, 270° = IX. В текущем ответе короткая стрелка 0°, длинная 108°: это наклон, нарисованный на картине-подсказке. Допуск — 7°, шаг точной подстройки — 6°. Угол картинки `Native Angle` учитывает, что длинная стрелка уже наклонена в исходном PNG; `Target Angle` задаёт ответ независимо от этого наклона.

`Dial Center = (938,479)` и `Dial Radius = 118` заданы в пикселях макета `1875×1902`. У каждой стрелки UV Min/Max убирают прозрачные поля только при отображении, Pivot задаёт точку крепления внутри этого прямоугольника, Size и Tip Length — размер и длину на часах. PNG не обрезались и не перезаписывались.

В `DA_Inspection_FloorClock → Pickups[0]`: Pickup ID = `FloorClock_PunchCard`, Item ID = `PunchCard`, Position = `(720,1070)`, Size = `(430,258)`. Это отдельная перфокарта от шкафной: одинаковый тип предмета и разные размещения/прогресс.

### Оформление часов

Все сообщения часов, включая второй этап, написаны на английском. Управление разбито на отдельные строки в нижней панели; прежняя подсказка Escape скрыта только у часов, поскольку она уже включена в эту панель. Шрифт `F_IMFellEnglish` находится в `/Game/NENS/UI/Fonts` и назначен через `Interface Font`. Это [IM Fell English Roman из Google Fonts](https://github.com/google/fonts/tree/main/ofl/imfellenglish), SIL OFL 1.1. Исходник и лицензия лежат в `Content/NENS/UI/Fonts/Source/IMFellEnglish`; лицензия включается в игровые дистрибутивы через RuntimeDependencies.

Длина от крепления до конца короткой стрелки — 54, длинной — 104 пикселя макета. `Size` пропорционально согласован с `Tip Length`, поэтому отображение и захват мышью совпадают. На подставках обе стрелки направлены вверх и увеличены одинаково в `Tray Scale = 2.5`; различие длин сохраняется после установки. Симметричные узкие карточки находятся слева и справа от корпуса: `Tray Position = (260,740)` и `(1615,740)`.

`Tools/style_clock_inspection.py` применяет это оформление к существующим часам. Он меняет только шрифт, размеры стрелок и размещение подставок; правильные углы и настройки решения не сбрасывает. Для нового набора ресурсов его автоматически вызывает основной configure-скрипт. Исходные PNG не меняются.

## Где находится логика

В `BP_FloorClock → Components → Searchable` теперь компонент класса **ClockInspectionComponent**, наследник прежнего SearchableComponent. Его Scene указывает на данные открытого отделения, Puzzle — на данные механизма, Scene Widget Class — на WBP_ClockInspection.

`Event Interact → Open Inspection(Self, Interactor)` и `On Inspection Closed → Branch Completed → скрыть подсказки` остаются обычными редактируемыми графами Blueprint. `On Item Collected` передаёт подтверждённый Item ID для будущего инвентаря; `On Puzzle Solved` отдельно сообщает о решении механизма, если позже понадобится звук или открытие двери.

Новые C++ классы в `Source/NENS_Project/Public` и `Private`:

- `ClockPuzzleData` — настраиваемый макет и проверка настроек.
- `ClockInspectionComponent` — установленные стрелки, углы, необратимое решение текущего запуска и запрет взять карту до решения.
- `ClockInspectionWidget` — мышь, захват/отпускание, выбор стрелки, плавный переход и сохранённый второй этап.

Используются прежние `InspectionSubsystem` и `InteractionSessionSubsystem`: дополнительных окон/переключений ввода между этапами нет. Общий сеанс теперь освобождает захваченную окном мышь перед удалением окна, чтобы Escape во время перетаскивания не оставлял захват на старом виджете. У SearchableComponent.TryCollect и InspectionSceneWidget.Configure добавлено виртуальное расширение для специализированных часов; стандартный сбор предмета по-прежнему выполняет общий механизм осмотра.

`Tools/configure_clock_inspection.py` импортирует четыре текстуры и создаёт ресурсы данных; существующие настройки при повторном запуске не сбрасывает. Editor API подключает только часы и их WBP. Общий WBP осмотра, карта, мебель и PNG не перезаписываются. Перед настройкой создана копия `Saved/ClockPuzzle/backup-before-clock`.

## Проверки

`NENS.Inspection.Clock.PIEFlow` проверяет настоящий маршрут мыши Slate: неудачный/успешный бросок, вращение, точную подстройку, выбор Tab, Escape с захваченной мышью, сохранение положения, решение, выход во время перехода, повторный вход в отделение, клик по карте, запрет дублей, независимые часы, полный плавный переход и отключение подсказок после сбора.

`NENS.Inspection.Clock.ProgressAndValidation` проверяет запрет преждевременного сбора через базовый компонент, неверные углы/данные, переход через 0°/360°, отдельность решения и сбора.
