# Восстановление главного компьютера

Игрок восстанавливает четыре системы, находит две перфокарты и загружает программу в терминал. Всё можно делать в любом порядке. Карты можно загружать по одной. После выполнения требований кнопка **Restore computer** запускает трёхсекундное восстановление; оно продолжается даже при закрытом окне. На основной карте затем появляется [финальный экран](GamePresentation.md); на отдельных тестовых картах завершённый терминал остаётся доступен для осмотра.

| Действие | Результат |
| --- | --- |
| Решить провода (`BP_Props_ElectroStation`) | Power supply — READY |
| Решить вентили (`BP_Props_PickMeBox`) | Fuel supply — READY |
| Решить диски (`BP_BedsideCabinet`) | Display — READY |
| Пройти вычисления (`BP_ComputerCabinet`), ответ 29 | Arithmetic check — READY |
| Забрать карту из шкафа | `Wardrobe_PunchCard` в сумке |
| Решить часы и забрать карту | `FloorClock_PunchCard` в сумке |
| Нажать Load punch cards | Найденные нужные карты переходят из сумки в считыватель |
| Нажать Restore computer | Запуск восстановления → COMPUTER ONLINE |

Записка со стола тоже запоминается в сумке, но в программе не используется. Повторный клик по собранному предмету ничего не выдаёт. Несколько копий одного типа карты не заменяют другую необходимую карту.

## Как поставить компьютер

1. В Content Browser найти **BP_Props_DataComputer**: `/Game/NENS/Environment/Interior/Props/Blueprints`.
2. Перетащить Blueprint на карту. Это уже готовый интерактивный объект с прежним спрайтом, белым кольцом и E.
3. Play → подойти в кольцо → E. На экране видны состояние четырёх систем, карты в сумке, загруженные карты и следующее действие.

На `L_MainRooms` декоративные спрайты электростанции и главного компьютера заменены готовыми интерактивными Blueprint с сохранением видимого положения, размера и материала. При наличии главного компьютера на карте справа сверху появляется небольшая панель цели; во время интерактивных сцен она плавно скрывается.

## Где менять настройки

- **DA_ComputerRecovery** в `/Game/NENS/UI/Recovery`: Card Scenes — перечень сцен с обязательными картами, Program Item ID — `PunchCard`, Restore Seconds — длительность восстановления. Сейчас включены обе существующие сцены с перфокартами. При добавлении новой сцены добавь её в Card Scenes; у каждой нужной карты должен быть свой Pickup ID.
- **WBP_ComputerRecovery**, там же: Designer — расположение, текст и кнопки; Class Defaults → Minigame → Transition / Mist / Appearance — плавность, дымка, шрифт, отступы.
- **BP_Props_DataComputer → Recovery**: Definition и Widget Class; Show Objective включает панель цели. Это общий прогресс одного компьютера на текущий запуск, поэтому несколько терминалов должны использовать один Definition.
- **BP_Props_DataComputer → Sphere_Interaction / Sphere_Awareness / Ring_Visual / Widget_InteractionPrompt**: расстояние взаимодействия и внешний вид подсказки. Радиус взаимодействия сейчас 90, обнаружения 190.
- Компонент **Minigame → Recovery → Repaired System** на четырёх объектах задаёт связь головоломки с системой. `None` оставляет обычную независимую головоломку.
- Событие **Recovery → On Restored** на компьютере позволяет подключить дверь, финальную сцену или звук. Общий `ComputerRecoverySubsystem → On Computer Restored` также доступен в Blueprint.

## Состояние и переходы

`ComputerRecoverySubsystem` принадлежит GameInstance: хранит собранные предметы, загруженные уникальные карты, решённые системы и состояние программы до конца запуска игры. После нового Play всё начинается заново; сохранения на диск нет. Ключ сбора включает путь игрового Actor, имя компонента и Pickup ID, поэтому отдельные размещённые копии независимы. При повторной загрузке того же размещения в рамках одного запуска сбор и успех головоломки сохраняются.

UI использует общий `InteractionSessionSubsystem` и `MinigameWidget`: только одно окно, блокировка движения, восстановление фокуса и ввода, плавный вход/выход, общий IM Fell English, процедурные градиент и дымка. Ввод заблокирован во время переходов. Закрытие терминала не отменяет таймер программы. Вызовы из старого окна не могут закрыть новый сеанс. Уничтожение владельца немедленно освобождает управление.

## Служебная настройка и проверки

`Tools/configure_computer_recovery.py` создаёт данные и интерфейс, переводит существующий BP_Props_DataComputer на общий интерактивный базовый класс и назначает системы головоломкам. Скрипт не редактирует карты и исходные изображения; для обычной работы левел-дизайнера запускать его не требуется. Перенос проводов и добавление вычислений описаны в [ArithmeticComputer.md](ArithmeticComputer.md).

Автотесты: `NENS.Recovery` проверяет конфигурацию программы, сумку и полный PIE-сценарий терминала; тесты `NENS.Interaction.Minigame` проверяют реальные победы в каждой головоломке и передачу результата соответствующей системе. Отчёты и снимки этой доработки находятся в `Saved/ComputerRecovery`.
