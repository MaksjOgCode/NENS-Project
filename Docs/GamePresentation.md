# Финал и эмбиенты

Готовая игра запускается с существующего главного меню `Lvl_MainMenu_test`. **Play** плавно открывает `L_MainRooms` и начинает новый забег. Прямой Play на игровой карте в редакторе тоже включает игровой эмбиент.

После успешного восстановления главного компьютера на основной карте:

1. Короткая пауза 1.2 секунды позволяет увидеть подтверждение восстановления.
2. Плавное затемнение закрывает текущий осмотр/головоломку.
3. Появляется финал: **The end**, **Thank you for playing!**, **The main computer is back online.**
4. **Main menu** возвращает в меню через затемнение; **Quit game** плавно завершает игру. В PIE выход останавливает Play, редактор остаётся открыт.

Esc не закрывает финал. Игровое управление за ним заблокировано. Повторный Play из меню сбрасывает собранные предметы, загруженные перфокарты, решённые системы и таймер восстановления. На отдельных тестовых картах финал автоматически не появляется.

## Где менять оформление

`/Game/NENS/UI/Ending/WBP_EndGame` — обычный Widget Blueprint с временным оформлением, общим IM Fell English, градиентом, дымкой и плавным появлением. Художники могут заменить фон и макет в Designer. Сохранить родителя `EndGameWidget` и имена кнопок `Btn_MainMenu`, `Btn_Quit`.

`/Game/NENS/System/DA_GamePresentation`:

| Настройка | Сейчас |
| --- | --- |
| Main Menu Map | `/Game/NENS/UI/MainMenu/Lvl_MainMenu_test` |
| Gameplay Map | `/Game/NENS/Maps/MainMap/L_MainRooms` |
| Ending Widget | WBP_EndGame |
| Ending Delay Seconds | 1.2 |
| Screen Fade Seconds | 0.75 |
| Audio Fade Seconds | 2 |
| Gameplay Volume | 0.65 |
| Main Menu Volume | 0.7 |

`BP_NENSGameInstance` в той же папке назначен в Project Settings → Maps & Modes → Game Instance Class. Его свойство Presentation ссылается на данные выше. Фоновый звук и переходы управляются одним `GameExperienceSubsystem` на запуск игры. Старые ноды Play/Quit в меню отключены от выполнения; текущие кнопки обрабатывает native-адаптер с затемнением. Художественный макет, анимация моргания и Options сохранены.

## Звуки

Импортированы в `/Game/NENS/Audio/Ambience`:

- **S_GeneralGamePlay_Ambient** — основной геймплей, осмотры, головоломки и финальный экран.
- **S_MainMenu_Ambient** — главное меню.

Оригиналы без изменений: `SourceArt/Audio/Originals`. Подготовленные WAV для импорта: `SourceArt/Audio/Loops`.

На стыке конца и начала сделано перекрытие 3 секунды с равной мощностью. Убрано постоянное смещение сигнала, громкость выровнена примерно до −24 dBFS RMS с ограничением усиления +6 dB; клиппинга нет. После перекрытия длительности петель — 105.095 и 112.751 секунды. Плавный вход и смена окружения дополнительно обрабатываются аудиодвижком. Это RMS-нормализация, не измерение LUFS.

SoundWave настроены на Looping, Music, Play When Silent, Retain On Load и Compression Quality 80. Переходы между игровыми картами не перезапускают тот же трек. При возврате в меню предыдущая дорожка затухает, новая появляется; лишние копии не накапливаются. Начало/конец сцен головоломок не прерывают эмбиент. При завершении Play аудиокомпоненты освобождаются.

Громкость менять в DA_GamePresentation. Для замены самого звука — импортировать новый SoundWave с Looping и назначить его здесь. Перед импортом материала со слышимым обрывом нужно снова подготовить стык.

Служебные скрипты: `Tools/prepare_ambience.py` (NumPy и libsndfile из UE), `Tools/configure_game_presentation.py` (импорт и Blueprint). Для обычной работы с уровнем запускать их не требуется. Оба уровня включены в Maps to Cook; сцена уровня при этой доработке не пересохранялась.

## Проверки

`NENS.GamePresentation` проверяет реальные кнопки меню, переход на основную карту, завершение таймера восстановления, замену модального окна финалом, возврат в меню, чистый новый забег и Quit в PIE. Аудиопроверки используют работающий аудиодвижок: оба трека перематываются к концу, затем проверяется продолжение воспроизведения после границы файла и отсутствие повторного запуска.

Запускать эти проверки **без `-nosound`**. Отчёты и снимки — `Saved/GamePresentation`; численные проверки PCM-стыка и громкости — `audio-preparation.json` в этой папке.
