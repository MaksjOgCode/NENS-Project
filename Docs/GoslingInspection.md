# Повторяемый осмотр картины

`BP_Furniture_Gosling` открывает `T_Inspection_Gosling` через общий `WBP_InspectionScene`. E в зоне взаимодействия показывает арт и курсор, движение блокируется. Escape закрывает арт и возвращает управление, в том числе после клика по изображению. Просмотр можно повторять без ограничений.

## Настройки в редакторе

- Объект: `/Game/NENS/Environment/Interior/Blueprints/BP_Furniture_Gosling`.
- Данные: `/Game/NENS/UI/Inspection/DA_Inspection_Gosling`.
- Background: существующая `/Game/NENS/Environment/Interior/Textures/T_Inspection_Gosling`.
- Canvas Size: `2480 × 3508`, пропорции исходного арта.
- **Pickups: пустой массив**. Это режим подсказки: собирать ничего не нужно, сцена не считается завершённой, E и кольцо сохраняют обычное поведение при входе/выходе из зоны.

Для замены арта меняй Background и Canvas Size в ресурсе данных. Виджет масштабирует портрет целиком с сохранением пропорций. Отдельный спрайт арта для этого экрана не требуется; существующий `SPR_Inspection_Gosling_Sprite` оставлен без изменений.

В Blueprint картины компонент **Searchable** использует `DA_Inspection_Gosling` и `WBP_InspectionScene`. `Event Interact` вызывает `Open Inspection(Self, Interactor)`. Общий обработчик `On Inspection Closed` скрывает индикаторы только при Completed=true; для пустого массива предметов этот флаг всегда false.

Игровой C++ механизм не менялся: повторяемые сцены без предметов уже поддерживаются. Python `Tools/configure_gosling_inspection.py` нужен только для автоматического подключения этого объекта; он не импортирует дубликаты, не перезаписывает исходные PNG и не сохраняет карту. Общая архитектура описана в [InspectionSystem.md](InspectionSystem.md).

## Проверка

`NENS.Inspection.Integration.PIEGosling` открывает арт через существующий BPC, проверяет отсутствие предметов, пропорции портрета, Escape после клика, восстановление управления и три повторных просмотра с выходами из зоны и возвращениями. Проверяется, что индикаторы не отключаются как у завершённой мебели и материал кольца инициализирован.

Отчёт и снимок экрана: `Saved/GoslingInspection/Automation/index.json`, `Saved/GoslingInspection/gosling-open.png`. Резервная копия до настройки: `Saved/GoslingInspection/backup-before-gosling`. Размещение картины на `L_WallTest` и исходные изображения созданы пользователем и сохранены.

Проверка 18 октября 2026: сборка Editor успешна, Blueprint компилируется с 0 ошибок и 0 предупреждений. Все 8 тестов `NENS.` прошли без ошибок и предупреждений, включая три просмотра картины и регрессию стола, шкафа и проводов. Новых `Accessed None`/`RingMID` нет. Сравнение подтвердило сохранность исходных настроек компонентов, текстур, спрайтов и текущего пользовательского размещения на карте; изменён только Blueprint картины и создан её Data Asset. Арт визуально проверен по снимку. Тест вызывает существующий `TryInteract`; физическая E и иные размеры окна остаются ручной проверкой.
