# Ящик и головоломка с вентилями

Для расстановки используй **BP_Props_PickMeBox** в `/Game/NENS/Environment/Interior/Props/Blueprints`. Это прежний ассет с тем же путём: его экземпляры на карте получают взаимодействие после перезапуска Play. Текстура или отдельный SPR дают только изображение.

Ящик теперь наследует `BP_InteractableBase`: использует существующие Sphere_Awareness, Sphere_Interaction, белое кольцо и E. В компоненте **Minigame** назначен `WBP_ValvesBoard`. Вход открывает виджет в текущей комнате, персонаж и уровень не пересоздаются. Карта `L_valves1` остаётся самостоятельным стендом.

Виджет находится в `/Game/MiniGameValves2/WBP_ValvesBoard`:

- **Designer** — заголовок, управление, статус, Exit и положение всей сцены. Поле `Board` сохраняет исходные 1600 × 812 и координаты трёх вентилей; `ScaleBox_Minigame` вписывает всю композицию в окно.
- **Graph → Class Defaults → Minigame → Transition** — `Scene Fade In Seconds` (0.30) и `Scene Fade Out Seconds` (0.24).
- **Minigame → Mist** — `Mist Opacity` (0.42), `Mist Speed` (0.35), `Mist Height` (0.28). Ноль плотности отключает дымку.
- **Minigame → Appearance** — общий `Interface Font` IM Fell English и `Screen Padding` (32).

Градиент и движущаяся верхняя дымка рисуются процедурно при запуске, без новых текстур. Те же настройки переходов теперь доступны в `WBP_WiresMiniGame`; его выход через Esc, Exit и после победы тоже проходит через плавное исчезновение. Управление персонажем возвращается после исчезновения окна. Повторный Esc не перезапускает анимацию.

Каждое колесо — прежний `WBP_valves1` с исходным плавным поворотом на 90° по клику. Поверх колеса добавлена контрастная белая стрелка; неподвижный ромб показывает цель. При совпадении ромб заполняется, под полем показывается число совпадений. Подсказки на английском объясняют клик и совмещение меток.

Целевые значения остаются прежними: `Valve_Left` — 90°, `Valve_Top` — 180°, `Valve_Right` — 270°. Их можно менять у соответствующих виджетов через **Target Solution Angle**. Нулевое положение указателя направлено вверх, угол увеличивается по часовой стрелке. Победа принимается после остановки всех трёх колёс, а не при прохождении через цель во время поворота.

После успеха появляется `Flow restored`, затем окно плавно закрывается. У этого экземпляра ящика скрываются E и кольцо; сам ящик остаётся. Выход до победы создаёт новую попытку при следующем входе. Результат живёт до конца текущего Play, SaveGame не добавлен. Компонент `Minigame` предоставляет **On Succeeded** для подключения двери или следующего события.

`Tools/configure_valves_minigame.py` — первоначальная миграция через Unreal API, для обычного редактирования запускать её не требуется. Она изменяет три существующих Blueprint вентилей/ящика и пересохраняет виджет проводов после переноса общих параметров в `MinigameWidget`. Карты не сохраняются.

Runtime: `MinigameWidget` отвечает за общий фон, шрифт, дымку, ввод и переходы. `ValvesMinigameWidget` и `ValveControlWidget` добавляют метки, статус и проверку остановившихся колёс; исходные Blueprint сохраняют игровые правила и делегаты.
