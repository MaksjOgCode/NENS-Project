# Оформление мини-игры проводов

Открывай `/Game/Minigames/Wires/WBP_WiresMiniGame`. Правила трёх пар, кнопки, графы `CheckPair`, `Win` и `CloseMiniGame` остаются в этом Blueprint. Новый C++ родитель `WiresMinigameWidget` наследует прежний `MinigameWidget` и добавляет только оформление.

## Где менять внешний вид

В **Designer** теперь используется такая иерархия:

```text
CanvasPanel_248                         весь экран
  ScaleBox_Wires                       вписывает всё окно с сохранением пропорций
    SizeBox_WiresPresentation           размер макета 1440 × 1000
      Canvas_WiresPresentation
        TxtTitle                       заголовок
        SizeBox_115                     исходное поле 1280 × 720
          Board                        фон, шесть кнопок, изображения проводов
        TxtStatus                      ответ на выбор пары / победа
        Text_WiresControls             управление на английском
        BtnClose                       кнопка Exit
```

Все элементы макета масштабируются вместе. На маленьком, квадратном или широком экране окно остаётся по центру и целиком помещается в область игры. Градиент закрывает весь экран, поэтому за краями окна не выглядывает игровая комната.

У исходного фона есть непрозрачные чёрные поля. Для `Board → Img_Bg` задана обрезка UV по X от 0.092 до 0.902, Position X=117.76 и Size X=1036.8. Так убраны боковые поля, а само изображение осталось на прежнем месте относительно разъёмов. Текстура и координаты кнопок не изменены.

Размеры текста, цвета, подписи, позиции заголовка и управления можно менять в Designer. Используется тот же **IM Fell English**, что в осмотре шкафа и часов. Не переименовывай `Board`, кнопки `BtnL0…2`/`BtnR0…2`, `TxtStatus` и элементы, к которым обращаются графы.

В **Graph → Class Defaults** доступны:

| Поле | Значение по умолчанию | Назначение |
|---|---:|---|
| Interface Font | F_IMFellEnglish | Общий шрифт заголовка, статуса, управления и Exit; размеры берутся из Designer |
| Screen Padding | 32 | Отступ всего макета от краёв экрана в единицах UMG; больше значение — меньше окно |
| Mist Opacity | 0.42 | Плотность верхней дымки; 0 отключает эффект |
| Mist Speed | 0.35 | Скорость движения; 0 останавливает |
| Mist Height | 0.28 | Доля высоты экрана, занятая дымкой |

После изменений: **Compile → Save**, затем новый Play. Настройки шкафа в `WBP_InspectionScene` независимы от проводов.

Градиент и дымка создаются при запуске, поэтому их нет в сохранённом дереве Designer. Они используют общие `InspectionBackdrop.h` и `InspectionMist.h`, не требуют новых текстур или материалов и пропускают клики к кнопкам.

## Исходники и служебная настройка

- `Source/NENS_Project/Public/WiresMinigameWidget.h` и `Private/WiresMinigameWidget.cpp` — параметры оформления и создание процедурных эффектов.
- `Source/NENSInspectionEditor/Private/WiresPresentationSetup.cpp` — перенос существующих элементов в масштабируемый макет через Unreal API. Содержимое `Board` и игровые графы не пересоздаются.
- `Tools/style_wires_minigame.py` — первоначальное применение оформления и проверка сохранности графов/поля. Повторный запуск не перестраивает уже оформленный макет; для обычного редактирования запускать его не нужно.
- `Source/NENSInspectionEditor/Private/Tests/MinigameIntegrationTests.cpp` — проверка поведения и разметки при изменении окна.

Сценарии выхода, повторной попытки и победы описаны в [MinigameIntegration.md](MinigameIntegration.md). Их протокол не менялся: незавершённая попытка при повторном входе начинается заново, победа отключает взаимодействие с конкретным компьютером.

## Проверки 19 октября 2026

Сборки `NENS_ProjectEditor Win64 Development` и `NENS_Project Win64 Development` успешны. Полный набор `NENS.*`: **11 тестов прошли**, ошибок и предупреждений тестов нет. В сценарий проводов добавлены проверки центрирования, размещения всех кнопок/подписей в пределах окна, сохранения пропорций и кликов после изменения размера окна: 1700×950, 1000×900, 2000×850. Это размеры окна редактора; область самой игры меньше из-за панелей редактора.

Повторно проверены неверная/верная пара, три соединения, выход, сброс незавершённой попытки, скрытие индикаторов после победы, защита от старых отложенных вызовов и самостоятельный `L_Test_Wires`. Все исходные графы совпадают с резервной копией, кроме пересоздаваемых компилятором ID скрытых неподключённых пинов. Внутри `Board` изменены только UV и прямоугольник `Img_Bg`.

Сравнение двух снимков с интервалом около 1.2 секунды подтвердило движение дымки: 32888 изменившихся пикселей в верхней области, максимальная разница канала 8; в нижней области изменения отсутствуют. Проверка хешей Content подтвердила изменение только `WBP_WiresMiniGame.uasset` в рамках этой задачи. Предыдущие ручные изменения шкафа, карты и осмотра сохранены.
